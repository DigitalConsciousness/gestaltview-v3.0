# FAQ

## Is this a full clone of the internal GestaltView runtime?

No. This package is a client-safe scaffold built to preserve the commercial surface without exposing protected internal systems.

## Does it include hosted infrastructure?

No. Buyers bring their own Supabase project, provider keys, and deployment target.

## Can this be rebranded?

Yes. The package is designed for white-label use through environment-driven naming and styling.

## Is the retrieval system production-ready?

The schema and RPCs are real. The runtime adapters and provider calls are scaffolded and meant to be completed in the target deployment.

## Can this be extended for a vertical or client?

Yes. That is one of the main reasons the package exists.
