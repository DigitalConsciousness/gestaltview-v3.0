# Routing Guide

## Start here
- Use `gestaltview-ecosystem-orchestrator` when the first problem is figuring out the right lane.
- Use `gestaltview-suite-orchestrator` when work spans multiple domains and needs sequencing.
- Use `gestaltview-repo-onboarding` for fast repo orientation.
- Use `gestaltview-app-runtime` for live app behavior, routes, and runtime fixes.
- Use `gestaltview-billy-intelligence` for Billy grounding and retrieval.
- Use `gestaltview-schema-supabase` for Supabase tables, RLS, retrieval, and migrations.
- Use `gestaltview-agent-trainer` for trainer runs, evaluations, packaging, and generated artifacts.
- Use `gestaltview-admin-trainer-personhood` for personhood, embodiment, agent knowledge library, and mutation governance.

## Rule
Route to the smallest strong lane first.
Escalate to suite/orchestrator only when the task clearly spans multiple lanes.
