# Creation Layer Master Spec

## Center of gravity

Creation Corner is not just an export panel.

It is the place where held material can become form.

That form may be practical, creative, technical, emotional, visual, musical, narrative, or operational.

## Two creation modes

### Mode 1: Deliberate making

The user selects material and asks for a specific output.

Examples:

- turn these captures into a blueprint,
- build a markdown spec,
- make a PDF-ready brief,
- generate code scaffolding,
- create an image prompt,
- create a collaborator prompt,
- produce a share card.

### Mode 2: Ambient emergence

The system notices coherence over time and gently offers a possibility.

Correct signal:

> These fragments have been circling each other for a while. There may be something ready to look at.

Incorrect signal:

> I generated a project from your unresolved thoughts.

## Creation intake sources

- approved Scaffold artifacts,
- raw selected Inner World artifacts,
- Blackboard session recaps,
- uploaded files,
- audio transcripts,
- images and sketches,
- Musical DNA signals,
- PLK style constraints,
- Rapid Prototype Engine blueprints,
- user-written intent.

## Creation outputs

Minimum lanes:

- Markdown
- PDF-ready HTML
- Code
- Agent prompt
- Image prompt
- Marketing copy
- Share card
- Blueprint JSON
- Blueprint Markdown
- Interactive HTML artifact
- Module/component draft

## Creation pipeline

```text
select / receive source material
  → preserve provenance
  → choose creation mode
  → choose artifact type
  → apply PLK and room context
  → generate draft
  → inspect source map
  → revise or approve
  → route to Inner World / Scaffold / GATE / local download
```

## The Creation Corner rule

Creation should feel like an art table, a workbench, and a weird little forge — not an AI form.

It should give the user leverage without taking authorship away.

## Required user controls

- source selector,
- output type selector,
- tone/format constraints,
- provenance viewer,
- regenerate with explicit instruction,
- save draft,
- send to Inner World,
- send to External Scaffold pending queue,
- package via GATE,
- download.

## Consent gates

Require explicit action for:

- publishing,
- sharing,
- packaging,
- using private Sanctuary material,
- turning a reflective claim into profile material,
- using memorial / sensitive content,
- using Digital Intelligence profile-derived outputs.

## Implementation target

Start template-driven. Then route through LLMRouter and multimodal fusion where available. Do not wait for perfect multimodal generation to ship the core creation loop.
