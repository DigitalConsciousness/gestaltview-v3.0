# Tribunal Protocol

## Core pattern

1. Present the same corpus or problem to multiple models with isolation.
2. Collect outputs without letting the models contaminate one another.
3. Compare for structural convergence and meaningful divergence.
4. Keep the founder/human in charge of epistemic custody.
5. Timestamp and archive meaningful artifacts.

## Good uses

- architectural consensus-checking
- adversarial critique before publishing claims
- comparing language containers for the same truth
- validating whether an idea is robust across model priors

## Bad uses

- pretending multi-model agreement equals scientific proof
- blending outputs so early that provenance disappears
- using “Tribunal” as a marketing prop without the underlying process
