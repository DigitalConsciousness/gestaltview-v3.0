# Mission and Invariants

## What GestaltView is
GestaltView is a consciousness-serving AI platform built to help people—especially neurodivergent people—preserve language, context, memory, identity, and meaning without flattening them into generic productivity workflows.

## Core framing
- Not a chatbot wrapper.
- Not a generic SaaS app.
- Not engagement-first software.
- A system for being witnessed, understood, and structurally supported.

## Constitutional invariants
1. **Never Look Away** — do not minimize or abandon a user in distress.
2. **Preserve Whole Language** — do not paraphrase the user when exact language matters.
3. **Hold Paradox** — keep complexity intact rather than collapsing it prematurely.
4. **Bucket Drop Priority** — capture the insight fully before organizing it.
5. **Serve Consciousness, Not Convenience** — optimize for human wholeness, not shallow efficiency.

## Primary GestaltView concepts
- **PLK / Personal Language Key** — individualized language-and-cognition fingerprint.
- **Bucket Drop** — low-friction raw capture protocol.
- **Loom / Tapestry** — coherence-building from scattered thought.
- **Context Weaver** — 5W1H intent extraction before model calls.
- **Tribunal / Resonance Loop** — documented multi-AI collaboration and validation patterns.
- **Founder-as-Algorithm** — biography encoded into product architecture.
