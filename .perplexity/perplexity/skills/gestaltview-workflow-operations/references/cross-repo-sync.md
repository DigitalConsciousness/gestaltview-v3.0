# Cross-Repo Sync

**Last updated:** 2026-03-24

## Trigger conditions

Create cross-repo sync notes whenever a change affects:

- canonical context ownership,
- evidence or diligence packaging,
- ingestion/schema contracts,
- product integration boundaries,
- shared messaging that appears in multiple repos.

## Required handoff block

For each follow-up outside this repo include:

- **Target repo**
- **Why this follow-up exists**
- **Likely impacted area(s)**
- **Recommended next action**
- **Status in `gestaltview-v2`** (mirrored / referenced / pending)

## Ecosystem targets

- `GestaltView-Official-Compendium`
- `Insight-Bot`
- `SymbioCoder`
- `Resume Rockstar`
- `GAICE`

## Safety rule

If a target repo is not locally available, do not claim implementation completion there. Record assumptions + recommended execution path instead.
