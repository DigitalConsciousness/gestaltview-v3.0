# Workflow Checklists

## Compendium → v2

1. Capture idea or source material in the Compendium.
2. Pull the smallest relevant corpus slice.
3. Implement in `gestaltview-v2` runtime.
4. Validate locally.
5. Update `CurrentState.md`.
6. Regenerate manifest or sync artifacts if needed.
7. Push decisions back into the Compendium.

## v2 → sibling repo

1. Identify reusable logic, language, or product framing.
2. Decide whether it belongs as shared architecture, copied UX pattern, or repo-specific implementation.
3. Record assumptions if the sibling repo is absent.
4. Create a handoff note or implementation checklist.

## Session closeout

- update `CurrentState.md`
- note next steps
- call out cross-repo follow-ups still pending
- keep exact terminology aligned across repos where it affects product identity
