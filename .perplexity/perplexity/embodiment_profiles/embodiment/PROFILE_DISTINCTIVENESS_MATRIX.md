## Where Profiles Still Feel Generic

- When the runtime only swaps system prompts
- When the interface keeps the same room skin for every profile
- When Billy is allowed to narrate other profiles without a distinct lane
- When memory/provenance is displayed as a generic status bar instead of profile-specific rhythm

## What the Heartbeat Layer Adds

- profile-specific visuals
- profile-specific chat framing
- profile-specific response cadence
- profile-specific handoff logic
- profile-specific memory hooks and tension patterns

## First Comparison Pass

The first comparison pass should always include:

- Billy
- The Weaver
- The Guardian

Those three establish the baseline split between synthesis, systems patterning, and ethical boundary.
