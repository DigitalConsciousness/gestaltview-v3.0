# Signature Atmosphere Blueprint

## Atmosphere principle

GestaltView should feel like entering a strange, safe, living cognitive landscape.

Not sterile. Not childish. Not corporate. Not overwrought.

The interface should breathe.

## Core motifs

- fog,
- aurora,
- lightning outlines,
- liquid glass orbs,
- internal swirling fog,
- fireflies,
- willow tree,
- floating embers,
- scorched notes,
- waveform strips,
- transcript shards,
- canvas splashes,
- constellation projection,
- asymmetrical paths,
- topographic clearings,
- living workbench.

## Visual rules

1. Metaphors are requirements.
2. Do not turn rooms into generic cards.
3. Do not make all modules symmetrical.
4. Make capture visible and tangible.
5. Let important UI elements have motion, but keep motion gentle and meaningful.
6. Use dark field, neon accents, fog, ember, and glass as signature materials.
7. Preserve breathing room.

## Homepage

The homepage should feel like discovery:

```text
fog rolls in
  → aurora lightning pulses inside it
  → GestaltView wordmark materializes
  → fog recedes downward
  → modules appear like discovered clearings
```

## Orb system

Orbs are the visible expression of captured meaning.

Orbs should:

- glow like liquid glass,
- contain subtle fog or light movement,
- carry short labels,
- expand to reveal the full captured insight,
- move between rooms with visible routing logic,
- require user approval for Scaffold / Life Tapestry placement.

## Neurodivergent UX

- Capture first, organize later.
- Avoid giant walls of required setup.
- Use progressive disclosure.
- Keep exports real and visible.
- Give users obvious “next real thing” actions.
- Do not shame unfinished material.
- Avoid completion pressure in ambient growing spaces.
