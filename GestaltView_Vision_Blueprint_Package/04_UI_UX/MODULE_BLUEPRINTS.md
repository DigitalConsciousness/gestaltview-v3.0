# Module Blueprints

## Dynamic Inner World

A living, explorable world-space where raw expression and finished artifacts become tangible, persistent, and walkable. This room should feel like a memory-museum, not a dashboard grid or a gallery of cards.

The reference atmosphere is a futuristic archive space: neural aurora, fog, liquid glass exhibits, deep midnight void, teal/cyan/emerald/electric-purple energy, and warm analog memory light. All original GestaltView aesthetic — no borrowed IP.

The room is driven by a deterministic world-space renderer that turns artifact data into a structured spatial layout plan (museum mode for small collections, constellation mode for mid-size, archive mode for large). The renderer renders only from a strict known-node registry — no arbitrary generated React, no unsafe runtime codegen.

The full council of Digital Intelligences is present here, not just Billy and one other. **Curator** is the room's primary guide: contextual, dismissible, never blocking navigation. Other DIs appear in the room as exhibit presences according to their embodiment profiles.

The six surfaces (forward wall, back wall, left wall, right wall, ceiling, floor) can hold scorched notes, transcript shards, waveform strips, image pins, code panels, canvas splashes, and unresolved fragments. The selected artifact is always spatially prominent. Resonance links appear as visible rails from the selected artifact to connected artifacts — not heavy graph spaghetti, lightweight pulse connections.

**Must not:** behave like a list, auto-convert raw artifacts into identity claims, delete older material because newer material arrived, reduce the DI council to a single agent, flatten into a card grid or feed, evaluate generated code at runtime.

## External Scaffold of View

A structural atlas of approved material and evidence-linked connections. It should feel like a living constellation / spiderweb, not a mind-map worksheet.

## Rapid Prototype Engine

A living workbench for ideas, files, apps, and projects. Aesthetic: analog-industrial plus cyberpunk weirdness. Output: blueprint, spec builder, push to Creation Corner.

## Creation Corner

The artifact forge. It receives blueprints, captures, files, and coherence signals. It outputs artifacts with provenance.

## Pull String

A sanctuary-adjacent space for life's hard parts. No pressure, no judgment, no forced recovery framing. The literal hanging string reveals resources only when pulled.

## Your Living Legacy

A living museum of accepted, meaningful artifacts and life arcs. Never impersonation. Never default assumptions. Curated but not performative.

## Daydreamer

A separate module for sleeping dreams and aspirations. Whimsical, unfinished, hopeful. Not collapsed into Living Legacy.

## Musical DNA

User-owned music import and pattern reflection. The user view must start blank, not with Keith-specific demo tracks.

## Workspace & Document Analysis

Scholarly but accessible deep analysis across files, URLs, research materials, and references.

## User's Room / Sanctuary

Private living canvas. Nothing emits automatically. User controls what becomes part of the broader system.

## Digital Intelligence Academy

Lifecycle and education surface for DIs. Should evoke growth and responsibility, not toy ownership or marketplace browsing.

## Cognitive OS

Optional app/add-on layer. Right tools appear when useful, not as forced modules.
