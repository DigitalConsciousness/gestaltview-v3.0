# Perplexity Research Brief

Research GestaltView from the standpoint of implementation integrity and category clarity.

Do not treat it as a chatbot wrapper or productivity dashboard.

Focus areas:

1. Room-based spatial UI patterns.
2. Evidence-linked personal knowledge systems.
3. Humane capture-first UX for neurodivergent users.
4. Consent-based memory and provenance patterns.
5. Multimodal creation engines with source maps.
6. Agent/personhood governance and packaging boundaries.
7. Supabase/Vercel free-tier implementation constraints.
8. Babylon / CSS 3D tradeoffs for six-surface rooms.

Output should separate:

- current repo facts,
- source doctrine,
- feasible implementation recommendations,
- external best practices,
- risks and constraints,
- what not to build yet.

Do not inflate claims. Ground everything.
