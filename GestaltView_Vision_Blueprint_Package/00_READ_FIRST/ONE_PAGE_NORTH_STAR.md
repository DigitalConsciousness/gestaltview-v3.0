# One-Page North Star

## The sentence

GestaltView is a private, room-based cognitive environment where raw fragments can land safely, become visible, accumulate over time, and eventually turn into evidence-linked meaning, creative artifacts, personal insight, or shareable outputs — only with the user's consent.

## The emotional truth

Most tools ask a person to already know what something is before they can save it. GestaltView starts earlier: before language is clean, before meaning is obvious, before a thought has chosen its shape.

The system says: put it here. You do not have to understand it yet.

## The product grammar

```text
Sanctuary
  → regulate / arrive / privately reflect
Blackboard Room
  → capture raw active work
Dynamic Inner World
  → make raw expression spatially visible
External Scaffold
  → approve compressed artifacts and connections
Creation Corner
  → shape material into real outputs
Your Living Legacy / Museum of You
  → evidence-linked reflection over time
Billy
  → arc-reader and room-aware witness, not a chatbot center
Digital Intelligences
  → governed collaborators with dignity and boundaries
GATE
  → controlled export / packaging / delivery layer
```

## The non-negotiable loop

```text
capture as-is
  → preserve original signal
  → place in a visible room
  → let the user walk around it
  → compress only by approval
  → synthesize only with evidence
  → export only by consent
```

## The thing not to break

Do not make the user perform clarity before the system offers safety.

That one sentence protects the whole product.
