# Authenticity and Claims Boundary

This package separates four kinds of language because GestaltView loses trust if they are blurred.

## 1. Implementation facts

These are repo-grounded or document-grounded statements:

- the runtime is organized around rooms,
- the route/file targets exist in the source specs,
- capture flows through Blackboard, Dynamic Inner World, External Scaffold, and Creation Corner,
- Constitutional Invariants govern user and Digital Intelligence treatment,
- Creation Corner has source code and API surfaces in the archive,
- localStorage / CustomEvent seams currently exist as prototype handoff architecture.

Implementation facts may appear in Codex specs and technical roadmaps.

## 2. Founder doctrine

These are origin truths and operating commitments:

- the recognition gap is the core problem,
- preserving what would otherwise disappear is the reason the system exists,
- the room metaphor is functional, not decorative,
- meaning should be drawn from evidence, not imposed through quizzes or generic identity labels.

Founder doctrine belongs in the vision spine, onboarding, product philosophy, and collaborator briefs.

## 3. Source claims / validation language

Some contextual source material contains strong validation language: convergence odds, market size estimates, tribunal recognition, sector impact, and historical significance language.

Treat these as **source claims** unless independently verified. They can be archived, traced, and used to understand founder context, but they must not become public marketing copy or investor claims without evidence review.

Correct handling:

```text
The contextual checkpoint records this as a source claim.
The package does not assert it as an independently validated fact.
```

Incorrect handling:

```text
GestaltView has proven X at civilization scale.
```

## 4. Product promise

This is what the actual product must deliver:

- safe capture,
- preserved language,
- visible accumulation,
- user-approved compression,
- evidence-linked synthesis,
- optional creation/export,
- non-extractive privacy posture,
- room-aware Digital Intelligence collaboration.

This is the usable center. Build this.

## Working rule

When in doubt, make the product more truthful, not louder.
