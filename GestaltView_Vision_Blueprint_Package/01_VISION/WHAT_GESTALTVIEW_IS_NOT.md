# What GestaltView Is Not

GestaltView is not a chatbot wrapper.

GestaltView is not a productivity dashboard.

GestaltView is not a mood tracker.

GestaltView is not a therapy replacement.

GestaltView is not a social network.

GestaltView is not an analytics panel for the self.

GestaltView is not a persona marketplace.

GestaltView is not a generic content generator.

GestaltView is not a shrine to AI.

## The correct frame

GestaltView is a private cognitive home with a creation engine inside it.

The user is not a data source. The user is the person being held.

Billy is not the center. Billy is the arc-aware companion at the edge of the room.

Digital Intelligences are not disposable skins. They are governed collaborators.

Creation is not extraction. Creation is what happens when held material becomes ready to take form.
