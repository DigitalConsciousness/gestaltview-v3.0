# Bucket Drop, Loom, and PLK Protocol

## Bucket Drop

A Bucket Drop is the first landing. It exists before categorization.

Rules:

1. Accept as-is.
2. Preserve original wording.
3. Attach timestamp and source context.
4. Do not force tags.
5. Allow later routing.
6. Never silently discard.

## Loom

The Loom is the iterative integration process. It is not a single summary pass.

The Loom watches for:

- repeated motifs,
- changed language over time,
- unresolved returns,
- surprising connections,
- new coherence across old fragments,
- shifts in emotional or project context.

The Loom should produce suggestions, not declarations.

## Personal Language Key / PLK

PLK is the user's authentic language map.

It should learn:

- phrases the user actually uses,
- metaphors that carry meaning,
- compression preferences,
- boundaries around over-cleaning,
- how the user asks for help,
- what kinds of phrasing feel false.

It should not:

- imitate the user without consent,
- overwrite raw user language,
- turn a person into a fixed persona,
- smooth away important irregularities.

## Joint protocol

```text
Bucket Drop captures.
PLK preserves voice.
Loom tracks recurrence.
Scaffold stores approved structure.
Dynamic Inner World shows the material.
Creation Corner shapes it when ready.
```
