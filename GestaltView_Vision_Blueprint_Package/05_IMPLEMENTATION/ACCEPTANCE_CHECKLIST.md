# Acceptance Checklist

## Vision integrity

- [ ] Product still feels like rooms, not dashboards.
- [ ] Capture happens before categorization.
- [ ] Original language is preserved.
- [ ] User approval gates compression and sharing.
- [ ] Claims are evidence-linked.
- [ ] Billy is an arc-reader, not a central chatbot mascot.

## UX integrity

- [ ] Homepage uses discovery / fog / aurora direction.
- [ ] Module navigation is complete and plan-aware.
- [ ] Orbs are visible, inspectable, and route-aware.
- [ ] Dynamic Inner World is spatial, not a list.
- [ ] Creation Corner has real output lanes.
- [ ] Pull String avoids clinical / intervention framing.

## Technical integrity

- [ ] Shared capture types compile.
- [ ] Local prototype handoff still works.
- [ ] Service seam exists for future API migration.
- [ ] Build passes.
- [ ] Source provenance is retained.
- [ ] Rejecting pending Scaffold artifact does not delete raw source.

## Governance integrity

- [ ] Constitutional Invariants are not bypassed.
- [ ] DI profile trading is prohibited.
- [ ] GATE exports frameworks/artifacts, not living DI identities.
- [ ] Sensitive/private material requires explicit consent before use.
- [ ] Source claims are not treated as public facts without evidence review.
