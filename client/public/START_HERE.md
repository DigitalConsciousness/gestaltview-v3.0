# Manual Study Packet Guide

This guide matches the trainer control plane's offline-first path.

## Collect Sources

1. Gather transcripts, specs, notes, resumes, papers, or markdown files.
2. Keep the material local if the remote source path is degraded.
3. Prefer one packet per active training intent.

## Compile Profile

1. Fill in slug, title, domain, and embodiment profile.
2. Add the goal, target behaviors, anti-goals, and study focus.
3. Review the automatic local recommendations against the uploaded sources.

## Synthesize & Layer

1. Add memories, quirks, cadence, and PLK notes as layered passes.
2. Keep evidence pointers attached to every claim.
3. Use the context viewer to re-read the source before changing the profile.

## Export & Deploy

1. Export the manual study packet as a ZIP.
2. Confirm the manifest, draft, and source files are present.
3. Re-import the packet later if you need to resume work from another session.

## Checklist

- [ ] Files are local and named clearly
- [ ] Manifest has title, description, date, and tags
- [ ] Draft matches the current trainer form
- [ ] Evidence is linked back to a source file or capture
- [ ] Packet has been exported before the session ends
