# Resume Rockstar Module

Embedded workspace module for AI-assisted resume building.

## Routes
- `/module/resume-rockstar` — main editor

## MVP Features
- Section editor (objective, experience, skills, education)
- Live preview with template selection (modern, classic, minimalist, creative)
- Markdown / JSON / PDF export
- Auto-save to localStorage via Zustand persist
- AI-powered content suggestions (gated, via `/api/modules/resume-rockstar/suggest`)

## Deferred
- Social sharing
- Advanced analytics
- Template marketplace
- Collaboration / version history
