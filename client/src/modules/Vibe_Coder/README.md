# Vibe Coder Module

Embedded workspace module for musical DNA analysis and creative identity exploration.

## Routes
- `/module/vibe-coder` — main music input + vibe analysis

## MVP Features
- Music preference input (song title + artist)
- Vibe/personality analysis card with emotion scores
- Neural Aurora gradient visualization (emotion-to-color mapping)
- Creative exploration suggestions
- Session persistence via Zustand
- Link vibe to user PLK profile (via `/api/modules/vibe-coder/link-profile`)
