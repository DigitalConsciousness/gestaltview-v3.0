# Symbio Coder Module

Embedded workspace module for AI-assisted code understanding and transformation.

## Routes
- `/module/symbio-coder` — main editor + chat

## MVP Features
- Code snippet editor with syntax highlighting (textarea + mono font)
- Chat sidebar with multi-turn AI assistant
- Suggestion panel: explain / optimize / refactor
- Session persistence via Zustand
- Language selector (TypeScript, JavaScript, Python, SQL, Bash, JSON)

## Deferred
- REPL / code execution
- Live collaboration
- Advanced debugging tools
