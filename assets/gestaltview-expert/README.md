# GestaltView Expert Assets

This is the working artifact tree for the GestaltView Expert.

Suggested subfolders:

- `code/` for refactored source snapshots
- `components/` for UI/component experiments
- `captures/` for screenshots, transcripts, and evidence files
- `reports/` for findings, gap summaries, and bridge notes

The intent is not archival sprawl. Keep only the material that helps the next
session continue the same learning thread.
