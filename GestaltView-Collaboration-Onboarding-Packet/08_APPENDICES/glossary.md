# Glossary

## Canonical
Part of the curated default routing surface.

## Auxiliary
Present on disk, but not part of default routing.

## Orientation spine
Stable governed structure that changes slowly.

## Orientation delta
Current drift, blockers, focus, and changed assumptions.

## Orientation checkpoint
Fast-load summary built from spine plus delta.

## Reintroduction tax
The cost of repeatedly restating the same context to new collaborators.
