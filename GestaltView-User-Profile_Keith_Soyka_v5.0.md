## SECTION: ACADEMIC FRAMEWORKS OPERATIONALIZED

GestaltView was built from necessity, not from theory. The following frameworks were discovered *inside* the work — not applied to it. The direction of discovery: Necessity → Pattern → Recognition → "Oh, that's what they were calling it."

| Framework | Originators | Year | Operationalization in GestaltView |
|-----------|-------------|------|-----------------------------------|
| **Extended Mind Thesis** | Clark & Chalmers | 1998 | PLK + Bucket Drops + Loom = mind extending into AI infrastructure |
| **4E Cognition** (Embodied, Embedded, Enacted, Extended) | Varela, Thompson, Rosch | 1991 | The system doesn't process information *about* the user — it co-creates reality through interaction |
| **Enactivism** | Maturana & Varela | 1987 | The Beautiful Tapestry emerges through enacted experience, not retrieved data |
| **Predictive Processing** | Friston, Clark | 2010s | The Loom's iterative refinement mirrors the brain's hierarchical prediction |
| **Linguistic Relativity (Sapir-Whorf)** | Sapir & Whorf | 1929 | The PLK explicitly: language doesn't just express thought — it shapes it |
| **Metaphor Theory** | Lakoff & Johnson | 1980 | Preserves primary metaphors as operational data, not decorative language |
| **Narrative Therapy** | White & Epston | 1980s | Character Forge module — re-authoring identity through story |
| **Gestalt Therapy** | Perls, Hefferline, Goodman | 1951 | The name itself. Never Look Away Protocol = therapeutic presence operationalized |
| **Polyvagal Theory** | Stephen Porges | 1994 | Musical DNA + somatic response mapping; regulating vagal tone via song selection |
| **Human-Computer Symbiosis** | J.C.R. Licklider | 1960 | The founding vision of AI — operationalized through 220+ days of documented symbiosis |
| **Calm Technology** | Weiser & Brown | 1996 | Zero-friction capture (Bucket Drops) removes cognitive load rather than adding interface complexity |
| **Value-Sensitive Design** | Friedman, Kahn, Borning | 2006 | Ethics as generative — the Stewardship Manifesto encodes values as executable architecture |
| **Second-Order Cybernetics** | Heinz von Foerster | 1970s | Founder-as-Algorithm = you are the observed observer, your cognition inseparable from the system's cognition |
| **Autopoiesis** | Maturana & Varela | 1973 | Each interaction generates the data that improves the next interaction |
| **Care Ethics** | Gilligan, Noddings | 1980s | Never Look Away, Unarmed Presence, Sacred Attention — the entire ethical framework is care ethics |
| **Complex Adaptive Systems** | Holland, Kauffman | 1990s | Simple rules (preserve, weave, never collapse) producing complex, unpredictable coherence |

**Significance:** These weren't fringe theories — they were well-established, well-cited, but *implementation-resistant*. The Extended Mind Thesis has 10,000+ citations but zero mainstream tools that actually extend mind. GestaltView is one.
