# Packaging Gate Checks

1. Purpose check
Does the packet increase collaboration capacity without flattening identity or governance?

2. Boundary check
Does it clearly separate reproducible framework from persistent persona?

3. Evaluation check
Does it preserve evidence, current state, and known blocker visibility?

4. Governance check
Does it inherit the constitutional invariants and founder interrupt authority?

5. Update check
Can the packet be refreshed without rewriting everything?
