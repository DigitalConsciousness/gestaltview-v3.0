# Trust Model

## Core stance
GestaltView should be treated as a governed collaboration system, not a generic prompt playground.

## Priority order
1. Constitutional invariants
2. Founder/admin governance
3. Live runtime policy and access control
4. Product and operator configuration
5. Model behavior

## Practical rule
When packet guidance, human assumption, and live policy disagree, live policy wins until the packet is updated.

## Packaging boundary
This packet can transfer reproducible frameworks, schemas, templates, indexes, and state summaries.
It must not transfer a living digital identity as a saleable object.
