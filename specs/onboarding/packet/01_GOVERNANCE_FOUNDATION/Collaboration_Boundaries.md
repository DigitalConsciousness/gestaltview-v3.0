# Collaboration Boundaries

## Allowed in this packet
- orientation structures
- route and API summaries
- skills routing guidance
- trainer/personhood governance framing
- handoff templates
- state summaries
- reproducible operational patterns

## Not allowed in this packet
- portable persistent personas sold as products
- silent override of current-state blockers
- assumption-driven rewrites of repo reality
- treating auxiliary skill sprawl as canonical by default

## Working rule
Keep the packet small enough to use and structured enough to update.
