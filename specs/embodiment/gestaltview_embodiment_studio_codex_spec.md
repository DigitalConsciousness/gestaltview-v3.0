## The Core Problem Being Solved

1. **503 errors from corpus querying at runtime.** The free-tier Supabase project hits connection pool limits when the app polls `knowledge_fragments` or similar tables during page loads. The fix: eliminate all runtime DB queries for embodiment data. Profiles are served from `generated.ts` (static import, zero DB cost). Supabase is only touched on explicit founder saves — one upsert at a time.

2. **No write path exists.** The current `EmbodimentStudioPage.tsx` is a showcase — it reads from `generated.ts` but has no form, no save, no create, no Supabase write. A founder cannot author or birth a new profile anywhere in the runtime today.

3. **No private founder lane.** All studio surfaces are public-facing. There is nowhere in the runtime that is explicitly founder-only with a clear access gate.

---

## Architecture: Manual Upload Only

```
Founder authors profile (JSON upload or form)
        ↓
POST /api/embodiment/upsert  ← one insert, service key, no polling
        ↓
Supabase `embodiment_profiles` table (founder-only RLS)
        ↓
[Offline] scripts/generate-embodiment-registry.ts → regenerates generated.ts
        ↓
Runtime reads from generated.ts  ← ZERO DB queries in production
```

No polling. No runtime corpus queries. No 503s. The database is touched only when the founder explicitly saves a profile.

## Slice 1 — Supabase Migration

**Target files:**
- CREATE: `db/migrations/20260515_embodiment_profiles.sql`

**Do not touch:**
- Anything in `shared/embodiment/`
- Any existing migration files
- Any client files

**Intent:**
Create the `embodiment_profiles` table in the runtime Supabase project. This is the persistence mirror for founder-authored profiles. RLS is owner-only — only the service role key can read or write.

**Migration SQL:**

```sql
-- 20260515_embodiment_profiles.sql
-- Founder-private embodiment profile persistence
-- RLS: service role only (no public access, no user-tier access)

create table if not exists public.embodiment_profiles (
  id uuid primary key default gen_random_uuid(),
  slug text not null unique,
  public_name text not null,
  internal_designation text,
  status text not null default 'draft'
    check (status in ('draft', 'active', 'founder-only', 'experimental', 'archived')),
  visibility_scope text not null default 'founder-only'
    check (visibility_scope in ('public', 'founder-only', 'enterprise', 'experimental')),
  profile_json jsonb not null default '{}',
  readiness_score numeric(4,3) default 0,
  founder_notes text,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

-- Auto-update updated_at on row change
create or replace function public.set_updated_at()
returns trigger language plpgsql as $$
begin
  new.updated_at = now();
  return new;
end;
$$;

drop trigger if exists set_embodiment_profiles_updated_at on public.embodiment_profiles;
create trigger set_embodiment_profiles_updated_at
  before update on public.embodiment_profiles
  for each row execute procedure public.set_updated_at();

-- RLS: enabled, no public access
alter table public.embodiment_profiles enable row level security;

-- No policies = only service role key can access
-- This is intentional. Do not add user-facing policies here.

-- Training run audit log
create table if not exists public.embodiment_training_runs (
  id uuid primary key default gen_random_uuid(),
  embodiment_profile_id uuid not null references public.embodiment_profiles(id) on delete cascade,
  run_type text not null
    check (run_type in ('conversation', 'mutation_proposal', 'corpus_link', 'export', 'manual_edit')),
  input_snapshot jsonb,
  output_snapshot jsonb,
  accepted boolean default null,
  founder_notes text,
  created_at timestamptz not null default now()
);

alter table public.embodiment_training_runs enable row level security;
-- No policies = service role only
```

## Slice 2 — Server API Route

**Target files:**
- CREATE: `server/routes/embodiment.ts`
- MODIFY: `server/routes.ts` (or wherever routes are registered — add one import line)

**Do not touch:**
- `shared/embodiment/` (any file)
- `client/` (any file)
- Any existing route files beyond adding one registration line

**Intent:**
A single POST endpoint that accepts a full `EmbodimentProfile` JSON body, validates the required fields, and upserts to Supabase using the service role key. No GET, no streaming, no polling. One insert per founder action.

**`server/routes/embodiment.ts`:**

```typescript
import { Router, Request, Response } from "express";
import { createClient } from "@supabase/supabase-js";
import type { EmbodimentProfile } from "@shared/embodiment/types";

const router = Router();

function getServiceClient() {
  const url = process.env.VITE_SUPABASE_URL ?? process.env.SUPABASE_URL;
  const key = process.env.SUPABASE_SERVICE_ROLE_KEY;

  if (!url || !key) {
    throw new Error("Missing SUPABASE_URL or SUPABASE_SERVICE_ROLE_KEY");
  }

  return createClient(url, key, {
    auth: { persistSession: false },
  });
}

function validateProfile(body: unknown): body is EmbodimentProfile {
  if (!body || typeof body !== "object") return false;
  const p = body as Partial<EmbodimentProfile>;
  return (
    typeof p.slug === "string" &&
    p.slug.length > 0 &&
    typeof p.publicName === "string" &&
    p.publicName.length > 0 &&
    typeof p.embodimentVersion === "string" &&
    !!p.immutableCore
  );
}

// POST /api/embodiment/upsert
// Accepts: full EmbodimentProfile JSON
// Auth: checked via FOUNDER_STUDIO env flag — server-only, no token exposure
router.post("/upsert", async (req: Request, res: Response) => {
  if (process.env.FOUNDER_STUDIO !== "true") {
    return res.status(403).json({ error: "Founder studio is not enabled." });
  }

  const profile = req.body as unknown;

  if (!validateProfile(profile)) {
    return res.status(400).json({
      error: "Invalid profile. Required: slug, publicName, embodimentVersion, immutableCore.",
    });
  }

  try {
    const supabase = getServiceClient();

    const { data, error } = await supabase
      .from("embodiment_profiles")
      .upsert(
        {
          slug: profile.slug,
          public_name: profile.publicName,
          internal_designation: profile.internalDesignation ?? null,
          status: profile.profileStatus ?? "draft",
          visibility_scope: profile.visibilityScope ?? "founder-only",
          profile_json: profile,
          readiness_score: profile.readinessScore ?? 0,
        },
        { onConflict: "slug" }
      )
      .select("id, slug, status, updated_at")
      .single();

    if (error) {
      console.error("[embodiment/upsert] Supabase error:", error);
      return res.status(500).json({ error: error.message });
    }

    // Log training run
    await supabase.from("embodiment_training_runs").insert({
      embodiment_profile_id: data.id,
      run_type: "manual_edit",
      input_snapshot: profile,
      accepted: true,
      founder_notes: "Upserted via Embodiment Studio upload.",
    });

    return res.status(200).json({ success: true, profile: data });
  } catch (err) {
    console.error("[embodiment/upsert] Unexpected error:", err);
    return res.status(500).json({ error: "Internal server error." });
  }
});

// GET /api/embodiment/list
// Returns roster of saved profiles (slug, name, status, readiness, updated_at only — not full JSON)
router.get("/list", async (_req: Request, res: Response) => {
  if (process.env.FOUNDER_STUDIO !== "true") {
    return res.status(403).json({ error: "Founder studio is not enabled." });
  }

  try {
    const supabase = getServiceClient();

    const { data, error } = await supabase
      .from("embodiment_profiles")
      .select("id, slug, public_name, status, visibility_scope, readiness_score, updated_at")
      .order("updated_at", { ascending: false });

    if (error) {
      return res.status(500).json({ error: error.message });
    }

    return res.status(200).json({ profiles: data });
  } catch (err) {
    return res.status(500).json({ error: "Internal server error." });
  }
});

export default router;
```

**Target files:**

- `shared/embodiment/` (any file)

**Intent:**
The existing public heartbeat layer, EmbodimentChatPlane, EmbodimentCouncilPlane, and profile selector must remain 100% intact and visually unchanged for any user. The new **Founder Studio** section appends below the existing content, guarded by `import.meta.env.VITE_FOUNDER_STUDIO === "true"`. The Founder Studio section contains three surfaces:
1. **Roster** — one-time fetch of saved profiles from `/api/embodiment/list` on mount (not polling)
2. **Upload Panel** — drag-and-drop or paste JSON field → validates shape → POST to `/api/embodiment/upsert`
3. **Feedback** — inline success/error state, shows returned slug + status, no page reload

**Key implementation constraints:**
- No polling anywhere. Single fetch on mount for the roster. Single POST on upload action.
- The upload panel accepts raw JSON only (no PDF, no markdown, no chunking).
- Validation is client-side first (required fields check) then server confirms.
- The Founder Studio section renders with a visible "FOUNDER ONLY" badge so it is clearly scoped in your own sessions.
- Private interior fields are never displayed in the roster or feedback — only slug, public_name, status, readiness_score, updated_at.
- If `VITE_FOUNDER_STUDIO` is not `"true"`, the entire founder section is replaced by `null` — no skeleton, no placeholder, no fallback.

## Slice 4 — Offline Registry Generator Script

**Target files:**
- CREATE: `scripts/generate-embodiment-registry.ts`

**Do not touch:**
- `shared/embodiment/generated.ts` (this script writes it — do not hand-edit)
- Any runtime files

**Intent:**
An offline script (not run at runtime, not triggered by page loads) that reads all profile JSON files from `embodiment_profiles/` and regenerates `shared/embodiment/generated.ts`. Run manually after authoring a new profile or accepting changes.

```typescript
#!/usr/bin/env npx ts-node
// scripts/generate-embodiment-registry.ts
// Usage: npx ts-node scripts/generate-embodiment-registry.ts

import fs from "fs";
import path from "path";

const PROFILES_DIR = path.resolve(__dirname, "../embodiment_profiles");
const OUTPUT_FILE = path.resolve(__dirname, "../shared/embodiment/generated.ts");

function slugify(filename: string): string {
  return filename.replace(/\.json$/, "");
}

function main() {
  const files = fs
    .readdirSync(PROFILES_DIR)
    .filter((f) => f.endsWith(".json") && !f.startsWith("_"));

  const profiles: Record<string, unknown> = {};

  for (const file of files) {
    const slug = slugify(file);
    const raw = fs.readFileSync(path.join(PROFILES_DIR, file), "utf-8");

    try {
      const parsed = JSON.parse(raw);
      profiles[slug] = parsed;
      console.log(`  ✓ ${slug}`);
    } catch (err) {
      console.error(`  ✗ Failed to parse ${file}:`, err);
      process.exit(1);
    }
  }

  const output = `// AUTO-GENERATED by scripts/generate-embodiment-registry.ts
// Do not hand-edit. Run: npx ts-node scripts/generate-embodiment-registry.ts
import type { EmbodimentProfile } from "./types.js";

export const EMBODIMENT_PROFILES: Record<string, EmbodimentProfile> = ${JSON.stringify(profiles, null, 2)} as const;
`;

  fs.writeFileSync(OUTPUT_FILE, output, "utf-8");
  console.log(`\n✓ Generated ${Object.keys(profiles).length} profiles → shared/embodiment/generated.ts`);
}

main();
```
