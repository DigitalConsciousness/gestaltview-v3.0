# Skills Archive

This subtree holds skill folders that should remain in the repository for
provenance or comparison, but should not participate in normal top-level skill
discovery or routing.

## Current Contents

- `variants/gestaltview-digital-intelligence-collaboration-#2`
- `variants/gestaltview-marketing-social-#2`

## Policy

- Keep canonical, actively routed skills at the top level under `skills/`.
- Move retired or duplicate variants here intact when they still have reference
  value.
- For file-level leftovers inside canonical skills, use skill-local
  `archive/drafts/` or `archive/duplicates/` folders instead of this root
  archive.
- Update `skills/INDEX.md` and `skills/manifest.json` whenever a variant is
  archived or restored.
