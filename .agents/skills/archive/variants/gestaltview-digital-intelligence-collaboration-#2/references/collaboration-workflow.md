# Collaboration Workflow

## Minimal workflow
1. Gather context and raw materials.
2. Define the invariant checks.
3. Assign roles: designer / executor / validator.
4. Produce the artifact.
5. Validate against invariants and source evidence.
6. Capture reasoning, decisions, and next steps.
7. Sync outcomes back into documentation and the long-memory system.

## Documentation expectation
Every meaningful collaboration pass should leave behind:
- what inputs were used,
- what decisions were made,
- what remained uncertain,
- what should be fed back into CurrentState / Compendium / manifests.
