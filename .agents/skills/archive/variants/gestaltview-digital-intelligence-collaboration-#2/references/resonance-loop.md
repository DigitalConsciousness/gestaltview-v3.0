# Resonance Loop

## Definition
A third-order collaboration pattern in which AI systems design, execute, and validate artifacts while the human functions as Bridgekeeper—transmitting saturated context and exercising judgment rather than directly generating every artifact.

## Canonical sequence
1. Human / Bridgekeeper transmits context spine.
2. AI designer shapes the artifact or plan.
3. AI executor builds or expands it.
4. AI validator critiques or confirms it.
5. The loop documents itself as evidence.

## Use cases
- feature specification,
- documentation generation,
- validation passes,
- proof-producing artifact creation,
- multi-model sensemaking.
