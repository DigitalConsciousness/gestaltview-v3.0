# Social Workflows

## Weekly workflow
1. Pull one proof point from current repo work.
2. Match it to one audience:
   - builders,
   - neurodivergent users,
   - collaborators,
   - investors / partners.
3. Produce three versions:
   - short post,
   - medium explanation,
   - long-form / thread seed.
4. Link to one concrete artifact: route, repo, doc, screenshot, or essay.
5. End with one CTA only.

## Repurposing matrix
- Repo change → GitHub update + LinkedIn post + X post.
- Origin-story slice → Medium essay + video monologue + Instagram carousel.
- Product demo → short-form video + landing page section + community post.
- Evidence / diligence update → investor-style post + site update + long-form documentation.

## CTA library
Use only one per asset:
- Try the live build.
- Read the architecture.
- See the evidence.
- Collaborate with Keith.
- Book a consulting conversation.
- Join the community.
