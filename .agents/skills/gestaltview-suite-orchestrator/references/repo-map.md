# GestaltView Repo Map

## Purpose
Use this file to orient multi-repo work before loading more detailed skill references.

## System map
- **gestaltview-v2**
  - Public-facing runtime repo.
  - React/Vite app, Billy UI, APIs, diligence explorer, route-level exhibits.
  - Best source for live implementation details, deployment flow, environment variables, and current product surfaces.
- **GestaltView-Official-Compendium**
  - Sister knowledge repo.
  - Canonical memory, source corpus, transcripts, PDFs, investor materials, architecture history, and ingestion source material.
  - Use as the source of truth for deep context and raw evidence when available.
- **Insight-Bot / SymbioCoder / Resume Rockstar / GAICE**
  - Integrated or adjacent product repositories.
  - In this repo they appear mainly through route copy, metadata, exported artifacts, audit references, and ecosystem documentation.

## Common task-to-repo routing
- **Live UI, route, API, deploy, env, runtime debugging** → start in `gestaltview-v2`.
- **Canonical proof, PDFs, historical transcripts, investor materials, long-form corpus** → start in the Compendium.
- **Cross-product positioning or ecosystem strategy** → combine `gestaltview-v2` evidence with external repo references if available.
