# Neural Aurora Design System

## Core visual identity
- Primary teal: `#00D4FF`
- Dim teal: `#006B7F`
- Glow: `rgba(0,212,255,0.35)`
- Dark background: `#0A0F14`
- Card background: `#050A0E`
- Black: `#000000`

## Typography guidance
- JetBrains Mono for UI / Billy / technical surfaces.
- Inter for marketing pages unless an existing surface already establishes a different controlled palette.

## UI behavior cues
- Prefer dark, luminous, presence-oriented surfaces.
- Use scanlines and radial glow ambient effects on new page-level experiences.
- Favor clear, stable layouts over clever abstractions.
- Keep the tone intimate, witnessed, and legible rather than generic startup polish.
