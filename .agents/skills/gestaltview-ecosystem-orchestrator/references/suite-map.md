# GestaltView Skill Suite Map

## Purpose

This suite turns the repository into an operating system for future agents. Each skill owns a distinct planning or execution surface while keeping cross-repo context small.

## Skill index

| Skill | Use it for |
|---|---|
| `gestaltview-ecosystem-orchestrator` | First-pass routing across the whole ecosystem |
| `gestaltview-app-runtime` | Live app architecture, UI, pages, routes, validation |
| `gestaltview-billy-intelligence` | Billy, PLK, retrieval, provider cascade, voice, safety |
| `gestaltview-revenue-pricing` | Packaging, subscriptions, Stripe, offer ladders |
| `gestaltview-marketing-social` | Messaging, GTM, social, launch content, public voice |
| `gestaltview-executive-summary` | Executive summary, partner brief, founder/investor narrative |
| `gestaltview-timeline-evidence` | Timeline creation, proof chain, diligence, blockchain claims |
| `gestaltview-digital-intelligence-collaboration` | Resonance Loop, Tribunal, multi-AI workflows |
| `gestaltview-cross-repo-workflows` | Compendium sync, integrated repos, manifests, handoffs |

## Default task-to-skill mapping

- “Build / fix / redesign a page” → app runtime
- “Fix Billy / API routing / PLK / provider cascade” → Billy intelligence
- “What should we charge / package / monetize?” → revenue & pricing
- “Write launch copy / social strategy / Reddit post / landing page messaging” → marketing & social
- “Summarize the company for investors / partners / press” → executive summary
- “Build a verified timeline / prove a claim / prepare diligence” → timeline & evidence
- “Operationalize collaboration between Keith and multiple models” → digital-intelligence collaboration
- “Coordinate v2 with Compendium / SymbioCoder / Insight-Bot / Resume Rockstar / GAICE” → cross-repo workflows
