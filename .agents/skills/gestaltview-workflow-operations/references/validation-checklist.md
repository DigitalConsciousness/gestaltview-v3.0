# Validation Checklist

## Repo-level checks commonly expected here
- build succeeds for the client/runtime path,
- type checking succeeds where relevant,
- no merge conflict markers remain,
- env vars referenced are documented,
- Billy provider contracts remain intact,
- route wiring and key UI surfaces still work.

## Documentation / strategy work checks
- new files are discoverable and named clearly,
- claims are separated into verified vs inferred vs planned,
- cross-repo assumptions are called out,
- CurrentState reflects the latest pass.
