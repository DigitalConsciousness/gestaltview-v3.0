# Resonance Loop

## Essence

A third-order collaboration pattern in which one intelligence helps design, another helps execute, and another validates or critiques the output, while the human carries context across the loop.

## Practical use

Use the pattern when:
- one model is better at architecture
- another is better at implementation
- a third is useful as adversarial reviewer or validator
- provenance matters and should remain inspectable

## Minimum record to keep

- participants
- roles
- date/time
- source corpus or prompt bundle used
- major decisions
- what changed after validation
