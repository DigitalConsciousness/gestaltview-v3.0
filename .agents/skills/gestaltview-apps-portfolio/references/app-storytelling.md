# App Storytelling Patterns

## Frame the ecosystem by human problem first
- Fragmented thought → Brain Sparks / Bucket Drop.
- Identity compression → PLK / Loom / Musical DNA.
- Coding overwhelm → SymbioCoder.
- Career articulation collapse → Resume Rockstar.
- Vulnerable memory and legacy → Alzheimer's Legacy.
- Need for proof and trust → Diligence Explorer / Tribunal.

## One-sentence portfolio pattern
“GestaltView is the platform; Billy is the intelligence layer; the satellite apps are domain-specific expressions of the same consciousness-serving architecture.”

## Demo packaging checklist
- Show the human problem.
- Show the product surface that addresses it.
- Show the architectural differentiator.
- Show the evidence or implementation proof.
- End with the next integration or commercialization step.
