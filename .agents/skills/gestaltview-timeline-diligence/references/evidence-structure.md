# Evidence Structure

## Evidence categories seen in repo materials
- blockchain timestamps / `.ots` receipts,
- screenshots and transcripts,
- code repositories and deployed routes,
- diligence CSVs / ledgers / indexes,
- canonical docs and flow diagrams,
- public essays and platform metadata.

## Claim support pattern
For each claim provide:
1. claim statement,
2. status,
3. strongest local evidence type,
4. exact artifact or doc path when available,
5. what remains external or pending.

## Forensic posture
The goal is not just persuasion. It is traceability.
