# Social Playbook

## Channel angles

- **LinkedIn** — founder journey, architecture lessons, evidence-backed product building, partner/investor credibility.
- **Reddit** — one concrete problem, one working artifact, transparent limits, no hype inflation.
- **X / Threads / Bluesky** — shorter proof-led fragments, quotes from documented artifacts, launch beats.
- **Instagram / visual channels** — screenshots, timeline visuals, UI reveals, scanline/aurora aesthetics, short captions.

## Repeatable content pillars

1. Build-in-public proof
2. Neurodivergent-first product design
3. Billy / PLK / Bucket Drop education
4. Tribunal / Resonance Loop explanation
5. Evidence and diligence artifacts
6. Founder-as-Algorithm translation for broad audiences

## Post template

- Hook with a real problem or documented milestone
- Give one proof artifact or concrete system detail
- Explain why it matters to a real user
- End with one CTA: try, read, ask, or watch
