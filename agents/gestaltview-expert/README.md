# GestaltView Expert

Canonical spec: [../gestaltview-expert.md](../gestaltview-expert.md)

This folder is the persistent working surface for the GestaltView Expert.
Use it to keep cross-session learning, gap tracking, and refactor direction in
one place.

## Structure

- `learning/` holds the recursive why/what/how/where/when map.
- `assets/` at the repo root holds work products generated while the expert is
  doing deep dives or refactors.

The goal is simple: when the next session starts, the expert should know where
to resume without re-learning the same context from scratch.
