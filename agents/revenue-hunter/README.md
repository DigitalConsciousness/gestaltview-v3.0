# Revenue Hunter

This folder establishes a stable `agents/revenue-hunter` path without changing the repository's current flat-spec agent convention.

## Canonical files

- `../revenue-hunter.md` - source-of-truth agent definition with YAML frontmatter and operating prompt
- `../revenue-hunter-quickstart.md` - fast-start guide, activation phrases, weekly rhythm, and Skills Keeper handoff
- `./openai.yaml` - OpenAI-facing metadata for display name, short description, default prompt, and implicit invocation policy

## Use this agent when

- Near-term consulting revenue, offer packaging, pricing, or partnership outreach is the goal.
- A GestaltView capability needs to be translated into a sellable service or monetization lane.
- Revenue work is stalled and needs concrete next actions instead of more research.

- `I need money this month`
- `Help me package an offer and do outreach`
