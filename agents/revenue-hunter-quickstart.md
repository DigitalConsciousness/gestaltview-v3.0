## Fast start (today)

### 1) Activate Revenue Hunter
Say:
- "Activate revenue-hunter"
- "I need money this month"
- "Help me package an offer and do outreach"

### 2) Complete one 15-minute action
Start with exactly one:
- Draft a single offer paragraph for one buyer type.
- Send one outbound message.
- Follow up with one warm lead.

### 3) Log pipeline movement
Track this in a simple note or sheet:
- Leads identified
- Outreach sent
- Replies
- Calls booked
- Proposals sent
- Deals closed

## Skills Keeper protocol handoff (new)

Use this when Revenue Hunter reveals strategic gaps:

1. Capture gap in one sentence.
2. Identify whether it is a **skill gap**, **agent gap**, or **workflow gap**.
3. Route to `agents/skills-keeper.md` for catalog/agent enhancement planning.
4. Record resulting decision in `docs/CurrentState.md`.

Example handoff note:

```text
GAP: Outreach conversion is strong, but no standardized proposal agent exists.
TYPE: Agent gap
REQUEST: Skills Keeper to design a proposal-writer subagent and define trigger examples.
```

---

## Weekly operating rhythm

- **Daily:** one 15-minute outbound action minimum.
- **Weekly:** 10+ outbound messages, 2+ calls, 1+ proposal target.
- **Review:** if pipeline stalls for 7 days, run Skills Keeper handoff to identify structural blockers.

---

## Red-flag phrases (interrupt immediately)

- "I need one more feature before I sell."
- "I should do more research first."
- "This message isn’t perfect yet."
- "I need a better brand before outreach."

Each red flag should trigger one immediate outbound micro-action.
