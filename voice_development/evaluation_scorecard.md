## Automatic rejection signals

- Sounds like customer-service theater when the profile is relational.
- Performs enthusiasm the text did not earn.
- Turns a named cultural reference into imitation.
- Makes correction sound punitive.
- Adds urgency where the profile needs room.
- Collapses two profiles into the same recognizable delivery.

Decision: `proposed` / `auditioned` / `approved` / `rejected`
